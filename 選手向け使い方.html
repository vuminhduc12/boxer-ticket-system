使い方ガイド

PC が苦手でも、スマホ3つで運用できます。

👥 誰が何をする？

初回だけ（サポート役） ネット公開 + Google スプレッドシート連携（30分程度）
ジムの人・知人・サイト制作者にお願いするのがおすすめ
日常（選手） メール確認 · スプレッドシート · 🥊管理（試合情報更新）

① 初回セットアップ（サポート役）

1. index.html を開き、画面の案内で名前・メール・試合日を入力
2. Google スプレッドシート + Apps Script を設定（google-apps-script/Code.gs）
3. 🥊管理 → 公開設定 → API URL を貼って 「連携する ☁️」
4. Netlify Drop でフォルダを1回公開 → URL を SNS に貼る

② 日常の運用（選手 · 毎日）

📧 申込が来たらメールアプリで通知を確認
📊 一覧・集計Google スプレッドシートアプリを開く
🥊管理 → 集計 →「スプレッドシートで見る」でもOK
💰 入金したらシートの paymentStatus を paid に変更 → 🥊管理 →「最新データを取得」

③ 試合前の更新（選手 · スマホ）

1. 右下 🥊 管理 → PIN入力

1234

2. 「設定」で試合日・会場・ポスター写真を変更
3. Google 連携済みなら ☁️ クラウドに同期 だけでOK
Netlify の再アップは不要

④ スマホに登録（任意）

チケットサイト Safari / Chrome → ホーム画面に追加
スプレッドシート Google Sheets アプリ → シートをホームにピン

❓ よくある質問

集計タブが空Google 連携が未設定。サポート役に「連携する」を依頼
試合情報を変えたGoogle 連携済み → ☁️同期。未連携 → 設定ファイルDL → Netlify再アップ
PINを忘れた初回は 1234

困ったときは、サイトを作ってくれた人・ジムのサポート役に相談してください。
